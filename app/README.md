# LearnQuest — обучение по твоим материалам

Загружаешь конспекты, лекции, книги (PDF, DOCX, TXT, MD, HTML, PPTX и другие текстовые) — ИИ составляет курс:
модули → уроки → тесты, термины, практика. Ты учишься в браузере или в Telegram, получаешь XP, уровни,
серию дней и достижения. Уроки подстраиваются под то, как ты отвечаешь.

Работает **на твоём компьютере**, без аренды сервера. Модель — через открытые API: по умолчанию **бесплатные модели OpenRouter**, при желании — DeepSeek / Qwen (см. «Модели ИИ»).

---

## Быстрый старт (Windows)

1. Установи Python 3.11+ (python.org, галочка «Add to PATH»), если ещё нет.
2. Дважды щёлкни **`start.bat`**. При первом запуске он сам создаст окружение и поставит зависимости (≈1 минута), потом откроет `http://127.0.0.1:8000`.
3. Зарегистрируйся (первый пользователь становится администратором).
4. Впиши ключ OpenRouter — либо в **Настройки → Модель ИИ и ключи**, либо в файл **`.env`** (`OPENROUTER_API_KEY=...`). Токен Telegram-бота — туда же (`TELEGRAM_BOT_TOKEN=...`).
5. Нажми «Добавить курс», перетащи файлы — через 20–60 секунд курс готов.

### Модели ИИ (важно)
Приложение само выбирает лучшие **бесплатные** модели из каталога OpenRouter и перебирает их по очереди, если одна занята или ответила не по формату.
Проверено вживую на твоих тестовых PDF: `nvidia/nemotron-3-super-120b-a12b:free` строит курс, тесты, термины, практику и проверяет решения (по ~5–50 секунд на запрос).

> **DeepSeek и Qwen.** На момент сборки (октябрь 2026) в *бесплатном* каталоге OpenRouter DeepSeek и Qwen уже нет — там остались Nemotron, Gemma и др.
> Если они там снова появятся, приложение поставит их **первыми** автоматически. А пока есть три способа получить именно DeepSeek/Qwen
> (всё в **Настройки → Модель ИИ и ключи**):
> 1. **Дешёвый платный DeepSeek через OpenRouter** — включи переключатель «Разрешить дешёвые платные модели». Нужен баланс от $5 на openrouter.ai; курс обходится ≈ 5–15 центов.
> 2. **DeepSeek напрямую** — «Свой провайдер» → пресет *DeepSeek* + ключ с platform.deepseek.com (платный, очень дешёвый).
> 3. **Qwen бесплатно** — «Свой провайдер» → пресет *Cerebras (Qwen)* или *Groq (Qwen)* и бесплатный ключ с cloud.cerebras.ai / console.groq.com.
>
> Свой провайдер пробуется **первым**, при ошибке приложение переключается на OpenRouter.

### Ключ OpenRouter
1. Зарегистрируйся на <https://openrouter.ai> → **Keys** → *Create key*. Карта не нужна.
2. В <https://openrouter.ai/settings/privacy> включи **«Enable free endpoints that may publish prompts»** — иначе бесплатные модели ответят `404 No endpoints found`.
3. Вставь ключ в настройки приложения (или в `.env`) и нажми **«Проверить модель»**.

> **Лимиты бесплатных моделей.** OpenRouter ограничивает бесплатные модели: ≈20 запросов в минуту и ≈**50 запросов в сутки** на аккаунте без пополнения (после пополнения на $10 — ≈1000 в сутки).
> Приложение экономит запросы: курс из ~4–6 модулей — это около 15–25 вызовов (план модуля и входной тест — одним запросом, все термины модуля — одним, анализ — только когда ты буксуешь).
> Уроки готовятся заранее, пока ты проходишь предыдущий. Если лимит исчерпан, урок покажет ошибку и кнопку «Повторить» — продолжишь завтра (или подключи любой из вариантов выше).

### Telegram-бот
1. Токен от [@BotFather](https://t.me/BotFather) (`/newbot`) положи в `.env` (`TELEGRAM_BOT_TOKEN=...`) или в настройки.
2. **Настройки → Telegram → Подключить**: откроется бот, нажми *Start* — аккаунт привяжется.
3. В боте: `/courses` — курсы, `/stats` — статистика, `/remind 19:30` — время напоминания. Можно прислать файл — бот создаст курс.
   Бот работает, пока запущено приложение (он опрашивает Telegram с твоего ПК — ни сервера, ни вебхуков не нужно).

### Доступ с телефона
- В `.env` поставь `HOST=0.0.0.0`, перезапусти — приложение откроется с телефона в той же Wi-Fi сети по `http://<IP-компьютера>:8000`.
- Из любой точки без аренды сервера: [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) (`cloudflared tunnel --url http://localhost:8000`) даёт временный публичный адрес. Компьютер должен быть включён.

## Как устроен курс

| Тип урока | Что внутри | Время |
|---|---|---|
| **Входной тест** | вопросы: выбор ответа, несколько верных, вставь термин, вопрос по картинке (схема рисуется ИИ). Выявляет пробелы и знакомит с терминами | ~3 мин |
| **Термины** | 3 термина: 1) термин + описание → 2) термин + начало описания, ты дописываешь → 3) только термин, ты пишешь описание целиком. Ответы проверяются сразу, неверные возвращаются в конце | ~5 мин |
| **Проверка терминов** | выбери термин по описанию / описание по термину | ~2 мин |
| **Практика** (если в материалах есть задачи/код) | 1 задача, подсказки, проверка решения ИИ, разбор | ~5 мин |
| **Тест на методы** | какие приёмы из курса применялись в задаче | ~2 мин |
| **Контрольный тест** | вопросы + термины + описания. Если меньше 60% — «работа над ошибками» и повторный тест | ~6 мин |

**Адаптация.** В каждый запрос к модели уходит профиль ученика: слабые/сильные понятия (по всем ответам), недавняя точность, заметки методиста.
После модуля (если результат ниже 80% и раз в три модуля) ИИ анализирует успеваемость, обновляет заметки и при необходимости вставляет модуль-повторение.
Список уроков заранее не показывается — просто нажимай «Продолжить».

**Прогресс и цели.** Полоса прогресса по курсу, XP за курс, серия дней, тепловая карта активности (как у GitHub), недельный график, достижения.
Цель на курс: выбери срок — приложение посчитает, сколько минут в день нужно учиться, и покажет, выполнена ли норма сегодня.

**Уведомления.** Браузер (пока открыта вкладка) и Telegram (всегда): напоминание в выбранное время и «серия под угрозой» в 21:00.

## Устройство проекта

```
app/
  start.bat, run.py        запуск
  .env.example             шаблон настроек (копия → .env, в git не попадает)
  server/
    main.py                REST API (FastAPI)
    llm.py                 клиент LLM: свой провайдер → OpenRouter (бесплатные/дешёвые модели), повторы, починка JSON
    prompts.py             ВСЕ промпты (структура курса, старт модуля, термины, практика, контрольный, адаптация)
    generator.py           пайплайн: файлы → фрагменты → структура → модули → уроки (лениво, с предзагрузкой) → адаптация
    engine.py              прохождение урока: шаги, проверка ответов, XP (общий для сайта и Telegram)
    grading.py             мгновенная локальная проверка текстовых ответов (без ИИ)
    gamification.py        XP, уровни, серии, цели, статистика, достижения
    tgbot.py, notifier.py  Telegram-бот и напоминания
    ingest.py, svgtools.py чтение файлов; безопасные SVG-картинки в вопросах
    llm_mock.py            демо-режим без ключа (LLM_MOCK=1)
  static/                  интерфейс (чистый JS, без сборки)
  tests/                   сквозные проверки (мок-ИИ, фейковые OpenRouter и Telegram)
  data/                    база SQLite (создаётся сама, в git не попадает)
```

Промпты — в [`server/prompts.py`](server/prompts.py): единый системный промпт (правила: опора только на материалы, «лестница» от простого к сложному,
самодостаточные вопросы, качественные дистракторы, строго один JSON) + отдельные промпты задач со схемой ответа.
Верные и неверные варианты модель возвращает раздельно, а перемешивает сервер — нет «любимой» позиции ответа.

## Частые проблемы
- **«Не задан ключ OpenRouter»** — вставь ключ в настройках, затем «Повторить» у курса.
- **`404 No endpoints found`** — включи free endpoints в настройках приватности OpenRouter (см. выше).
- **Курс долго собирается** — бесплатные модели иногда отвечают 30–90 секунд; при перегрузке приложение само переключается на следующую модель.
- **PDF без текста** (скан) — нужен распознанный текст; запусти OCR и загрузи снова.
- **Бот молчит** — проверь токен («Настройки → Telegram»), бот работает только пока запущено приложение.
