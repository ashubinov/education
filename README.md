# LearnQuest — бэкенд

Приложение для обучения по твоим материалам: загружаешь конспекты (PDF, DOCX, TXT, MD, HTML, PPTX…), ИИ собирает курс — модули, уроки, тесты, термины, практику.
XP, уровни, серия дней, цели, статистика, Telegram-бот, готовые курсы по номерам.

| Репозиторий | Что внутри | Где работает |
|---|---|---|
| **[education](https://github.com/ashubinov/education)** (этот) | API на FastAPI, ИИ, Telegram-бот, база SQLite | Amvera (круглосуточно) |
| **[education-front](https://github.com/ashubinov/education-front)** | интерфейс (HTML/CSS/JS) | GitHub Pages |

---

## Деплой: чтобы всё работало, пока твой ПК выключен

### Шаг 0. Что нужно подготовить
- Аккаунт на [amvera.ru](https://amvera.ru) (там же пополни баланс по тарифу проекта).
- **Баланс DeepSeek** на [platform.deepseek.com](https://platform.deepseek.com) (раздел *Top up*, хватит нескольких долларов — курс стоит центы). Без баланса приложение работает на запасных бесплатных моделях OpenRouter, но у них лимит ≈50 запросов в сутки на всех.
- Репозиторий `education-front` должен быть **публичным** (GitHub Pages на бесплатном тарифе — только для публичных).
- Токен бота (`TELEGRAM_BOT_TOKEN`) и ключи уже лежат в твоём локальном `.env` — их придётся продублировать в Amvera (шаг 3).

### Шаг 1. Бэкенд на Amvera
1. Amvera → **Создать проект** → тип *Приложение*, название, например, `learnquest`; тариф — минимальный (хватает; приложение лёгкое).
2. Окружение определится из файла [`amvera.yml`](amvera.yml) в репозитории (Python 3.12, pip, порт 80, постоянная папка `/data`). Отдельно ничего выбирать не нужно.

### Шаг 2. Подключить GitHub (автодеплой при `git push`)
1. GitHub → *Settings → Developer settings → Personal access tokens → Fine-grained tokens* → создай токен для репозитория `education` с правами **Contents: Read** и **Webhooks: Read and write** (для приватного репозитория подойдёт и classic-токен с галочкой `repo`).
2. Amvera → проект → вкладка **«Репозиторий»** → выбери **GitHub** → событие *Push* → придумай **секрет** (запомни) → вставь токен → ветка `main` → скопируй показанный **адрес вебхука** → «Применить».
3. GitHub → репозиторий `education` → *Settings → Webhooks → Add webhook*: Payload URL = адрес вебхука, Content type = `application/json`, Secret = тот же секрет, событие *Just the push event* → Add.
4. Сделай любой коммит и `git push` (например, `git commit --allow-empty -m "deploy" && git push`) — Amvera заберёт код и соберёт проект. Дальше каждый `git push` обновляет сервер.

### Шаг 3. Переменные окружения (Amvera → проект → «Переменные»)
Ключи и токены добавляй как **Секреты**, остальное — обычные переменные. После изменений нажми **перезапуск** контейнера.

| Имя | Значение | Тип |
|---|---|---|
| `DEEPSEEK_API_KEY` | ключ DeepSeek | секрет |
| `OPENROUTER_API_KEY` | ключ OpenRouter (запасные бесплатные модели) | секрет |
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather | секрет |
| `JWT_SECRET` | длинная случайная строка. Получить: `python -c "import secrets; print(secrets.token_urlsafe(48))"` | секрет |
| `CORS_ORIGINS` | `https://ashubinov.github.io` | переменная |
| `ADMIN_USERNAME` | твой логин (станешь администратором) | переменная |
| `ALLOW_REGISTRATION` | `1` (после регистрации друзей поставь `0`) | переменная |

Остальное задавать не нужно: `AMVERA=1` задаёт сама платформа, и база кладётся в постоянную папку `/data` (переживает перезапуски и пересборки).

### Шаг 4. Домен
Amvera → *Настройки → Доменные имена → Добавить* → HTTPS → **«Бесплатный домен Амвера»**. Получится адрес вида `https://learnquest-<пользователь>.amvera.io`.
Проверка: открой `https://<адрес>/api/health` — должно быть `{"ok":true,…}`.

### Шаг 5. Фронтенд на GitHub Pages
1. В репозитории `education-front` открой [`config.js`](https://github.com/ashubinov/education-front/blob/main/config.js) и впиши адрес бэкенда: `window.LQ_API = "https://<адрес Amvera>";` → commit.
2. *Settings → Pages* → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется на `https://ashubinov.github.io/education-front/`. Зарегистрируйся — ты станешь администратором (логин из `ADMIN_USERNAME`).

### Шаг 6. Готовые курсы (каталог) на сервере
Готовые курсы лежат в файле **`catalog_seed.json`** на твоём ПК (в GitHub он не попадает): **№101 «Информационные системы поддержки принятия решений»**, **№102 «Операционные системы»** и **№103 «Анализ больших данных»**.
1. На сервере: Amvera → проект → *Данные* (папка `/data`) → загрузи `catalog_seed.json` (папка появляется после первого успешного деплоя) → перезапуск. Если каталог пуст, он загрузится сам.
   Либо без Amvera-интерфейса: на сайте **Настройки → Каталог готовых курсов → Импорт** (нужны права администратора, `ADMIN_USERNAME`). Импорт *заменяет* курсы с теми же номерами.
2. Друзья: кнопка **«📚 Каталог курсов»** на главной → ввести номер (101, 102 или 103) → «Добавить». Повторно добавить тот же курс нельзя; пройти заново — кнопка «🔁 Пройти заново» на странице курса.

### Шаг 7. Telegram
Бот работает на сервере (long polling, вебхук не нужен). **Не запускай его одновременно на ПК с тем же токеном** — Telegram отдаёт обновления только одному потребителю. На ПК в `.env` поставь `TELEGRAM_ENABLED=0`.
Привязка аккаунта: сайт → Настройки → Telegram → «Подключить».

### Если что-то не работает
| Симптом | Причина |
|---|---|
| Сайт открывается, но «Нет связи с сервером» | не вписан/неверен адрес в `config.js`, либо бэкенд не запущен — проверь `/api/health` |
| В консоли браузера ошибка CORS | в `CORS_ORIGINS` нет `https://ashubinov.github.io` (без `/` в конце и без пути) |
| «Нужно войти» сразу после входа | поменялся `JWT_SECRET` (токены сбросились) — просто войди заново |
| Курс не создаётся, «ключ отклонён» / ошибка 402 | на DeepSeek нет баланса или неверный ключ; запасной вариант — OpenRouter |
| Бот молчит | токен не задан, либо бот ещё запущен на ПК (`TELEGRAM_ENABLED=0` на ПК) |

## Безопасность (что проверено и настроено)
- **JWT**: HS256, срок 30 дней, `Authorization: Bearer`, секрет `JWT_SECRET`; «Выйти на всех устройствах» отзывает все токены (`token_version`). Куки не используются → нет CSRF и проблем со сторонними куки на другом домене.
- **CORS**: разрешены только адреса из `CORS_ORIGINS` (+ localhost), только нужные методы и заголовки, без credentials.
- **Валидация** ([`server/schemas.py`](server/schemas.py)): все JSON-запросы проходят Pydantic-схемы (типы, длины, форматы цвета/времени/даты, диапазоны), ошибки — на русском. Фронт дополнительно экранирует всё, что показывает (в том числе текст от ИИ).
- Пароли — scrypt с солью; ограничение попыток входа и регистраций по IP (учитывается `X-Forwarded-For`); лимиты на число курсов и «новых курсов в день» (защита платного ключа ИИ); лимиты размера файлов и запроса; заголовки `nosniff`, `X-Frame-Options`.
- Картинки-вопросы от ИИ (SVG) очищаются белым списком тегов и показываются через `<img>`, скрипты в них не выполняются.

## Локальный запуск (на ПК)
```
start.bat                 # создаст окружение, поднимет сервер на http://127.0.0.1:8000
install_autostart.bat     # (необязательно) автозапуск при входе в Windows
```
Папка `front/` (клон репозитория `education-front`) раздаётся бэкендом автоматически — тот же адрес, `config.js` не нужен.
Docker: `docker compose up --build` (бэкенд на `http://localhost:8000/api/health`, данные в томе).

База — SQLite (`data/learnquest.db`; в облаке `/data/learnquest.db`). Для друзей этого достаточно; PostgreSQL не используется.

## Модели ИИ
Цепочка: **DeepSeek (прямой API)** → свой OpenAI-совместимый провайдер → **OpenRouter** (платные DeepSeek по желанию, затем лучшие бесплатные модели каталога).
Если модель не ответила или вернула мусор — берётся следующая. Промпты — в [`server/prompts.py`](server/prompts.py).
Подробности и настройка — в **Настройки → Модель ИИ и ключи** (для администратора).

## Готовые курсы
Курсы каталога собраны **вручную по промптам приложения** (без внешней нейросети): `python scripts/author_catalog.py` запускает тот же пайплайн (разбор файлов, структура, план модуля, уроки), но каждый промпт сохраняется в `catalog_authoring/<номер>/<ключ>.prompt.txt`, а ответ кладётся рядом файлом `<ключ>.json` и проходит те же проверки, что и ответ модели. Когда есть ответы на всё, курсы получают номера и экспортируются в `catalog_seed.json`.
Для генерации курса нейросетью есть `python scripts/seed_catalog.py` (нужен ключ и баланс). Проверка готового каталога: `python tests/verify_catalog.py`.

## Друзья, подписи, администратор
- **Друзья**: вкладка «Друзья» → заявка по логину → друг принимает. Друзья видят прогресс друг друга (уровень, серия, XP, курсы, достижения, неделя); скрытые достижения не показываются.
- **Подписи на страничке друга**: до 40 символов, одна подпись от одного человека на одну страничку (повторная отправка заменяет прежнюю). Подпись видна на страничке только после одобрения администратором; автору показывается «на модерации». Подписи самого администратора публикуются сразу. При удалении из друзей подписи друг у друга исчезают.
- **Администратор** (`ADMIN_USERNAME`): вкладка «Админ» — очередь подписей (одобрить / отклонить) и список пользователей с поиском, уровнем, XP, числом курсов и последней активностью; кнопка «Заблокировать» (с причиной, которую увидит пользователь) и «Разблокировать». Заблокированный не может войти и пользоваться API, пропадает из списков друзей и очереди модерации, ему перестают приходить напоминания в Telegram. Администратора и себя заблокировать нельзя.

## Устройство
```
server/
  main.py        API: авторизация (JWT), курсы, каталог, уроки, статистика, Telegram
  schemas.py     Pydantic-схемы запросов
  auth.py        регистрация, вход, JWT
  catalog.py     каталог: номера, копии курсов, повтор, экспорт/импорт
  social.py      друзья, подписи с модерацией, список пользователей и бан
  generator.py   файлы → структура → модули → уроки (лениво, с предзагрузкой) → адаптация
  supplement.py  дополнение курса новыми файлами, предгенерация курса
  engine.py      прохождение урока: шаги, проверка ответов, XP
  llm.py         клиент LLM (DeepSeek/свой/OpenRouter), повторы, починка JSON
  tgbot.py, notifier.py, gamification.py, grading.py, ingest.py, svgtools.py, db.py, config.py
scripts/author_catalog.py  ручная сборка каталога (ответы пишет человек/ассистент)
scripts/seed_catalog.py    сборка каталога нейросетью
tests/                    сквозные проверки на мок-ИИ, фейковых OpenRouter и Telegram
amvera.yml, Dockerfile, docker-compose.yml
```
