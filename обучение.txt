курс должен быть разбит на модули, модули на уроки.
типов уроков в модуле несколько: первый - тесты, проверка где пробелы и введение в термины которые будут в модуле. тесты могут включать в себя ответы по картинке, дополнение терминов, выбора правильных вариантов для ответа на вопросы. минуты 3 должен пользователь тратить на тесты. далее в уроках прописывается после каких ставятся тесты;
второй - написание терминов. строится так: показ термина и описания -> показ  термина и части описания, остальную пользователь дописывает -> показ термина и пользователь дописывает полностью описания. на этот тип пользователь должен тратить минут пять, то есть 3 термина примерно. после этого урока тест где пользователь выбирает правильный термин по описанию или правильное описание к термину;
третий - практический, если в курсе предусматривается практика. решение задач, написание кода. 5 минут пользователь должен тратить. 1 задача гдето. после него тест на методы которыми он пользовался для решения задач исходя из курса.
четвертый - контрольный тест. включается в себя первый и второй тип уроков.
